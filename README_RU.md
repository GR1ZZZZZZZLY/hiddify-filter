# Подписка Hiddify без российских узлов

Шаблон раз в час загружает публичный `top100.txt`, удаляет узлы с российской
меткой страны, убирает точные дубликаты и публикует результат в
`subscription.txt`.

Исходник:

`https://raw.githubusercontent.com/0xRadikal/Free-v2ray-Configs/main/top100.txt`

## Установка через сайт GitHub

1. Создайте новый **публичный** репозиторий, например `hiddify-filter`, и
   добавьте при создании файл README.
2. Распакуйте этот архив и загрузите в корень репозитория всё его содержимое,
   включая каталог `.github`.
3. Откройте `Settings → Actions → General → Workflow permissions`, выберите
   `Read and write permissions` и сохраните настройку.
4. Откройте `Actions → Update filtered Hiddify subscription → Run workflow`.
5. После успешного запуска в корне появится `subscription.txt`.

Ссылка для Hiddify:

`https://raw.githubusercontent.com/ВАШ_ЛОГИН/hiddify-filter/main/subscription.txt`

## Настройка Hiddify

1. Добавьте указанную выше ссылку как новый профиль.
2. Назовите его, например, `TOP 100 без RU`.
3. Включите автообновление с интервалом один час.
4. Выберите группу `Lowest/Auto` либо `Balancer`.
5. После проверки нового профиля отключите или удалите старый профиль с
   исходной ссылкой, иначе можно случайно выбрать его снова.

## Что именно фильтруется

Скрипт проверяет имя каждого узла, включая имена внутри VMess и SSR, и удаляет
метки `🇷🇺`, `RU`, `RUS`, `Russia`, `Россия`, `Москва` и Санкт-Петербург.

Это фильтр по геометке исходной подписки. Он не может дать абсолютную гарантию
для ошибочно размеченного узла или конфигурации через CDN. После подключения
проверьте фактическую страну выходного IP на `https://ipinfo.io`.

## Важно

- Не помещайте личные или платные ключи в публичный репозиторий.
- Если исходник недоступен или после фильтра осталось меньше пяти записей,
  workflow завершится с ошибкой и не затрёт последний рабочий файл.
- GitHub может отключить расписание публичного репозитория после 60 дней без
  активности. В этом случае откройте вкладку Actions и снова включите workflow.
