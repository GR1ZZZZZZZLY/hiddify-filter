# Две подписки HAPP/Hiddify без российских узлов

Шаблон каждые 15 минут загружает публичный `top100.txt`, удаляет узлы с
российской меткой страны, убирает точные дубликаты и публикует два файла:

- `subscription.txt` — все протоколы без RU, как раньше;
- `reality_tcp.txt` — только `VLESS + TCP/RAW + REALITY + XTLS Vision` без RU.

Исходник:

`https://raw.githubusercontent.com/0xRadikal/Free-v2ray-Configs/main/top100.txt`

## Установка через сайт GitHub

1. Создайте новый **публичный** репозиторий, например `hiddify-filter`, и
   добавьте при создании файл README.
2. Распакуйте этот архив и загрузите в корень репозитория всё его содержимое,
   включая каталог `.github`.
3. Откройте `Settings → Actions → General → Workflow permissions`, выберите
   `Read and write permissions` и сохраните настройку.
4. Откройте `Actions → Update filtered Hiddify subscription → Run workflow`.
5. После успешного запуска в корне появятся `subscription.txt` и
   `reality_tcp.txt`.

Обычная ссылка для HAPP/Hiddify:

`https://raw.githubusercontent.com/ВАШ_ЛОГИН/hiddify-filter/main/subscription.txt`

Рекомендуемая строгая ссылка:

`https://raw.githubusercontent.com/ВАШ_ЛОГИН/hiddify-filter/main/reality_tcp.txt`

## Настройка HAPP или Hiddify

1. Добавьте строгую ссылку `reality_tcp.txt` как новую подписку.
2. Назовите её, например, `REALITY TCP без RU`.
3. Выберите интервал автообновления 15 минут, если приложение его предлагает.
   Иначе оставьте один час и включите обновление при открытии.
4. Выберите группу `Lowest/Auto` либо `Balancer`.
5. Обычный профиль `subscription.txt` можно оставить как резервный, но не
   включать его автоматический выбор одновременно со строгим.

## Что именно фильтруется

Скрипт проверяет имя каждого узла, включая имена внутри VMess и SSR, и удаляет
метки `🇷🇺`, `RU`, `RUS`, `Russia`, `Россия`, `Москва` и Санкт-Петербург.

Для `reality_tcp.txt` дополнительно обязательны все условия:

- схема ссылки — `vless://`;
- транспорт `type=tcp`, `type=raw` либо `network=tcp/raw`;
- `security=reality`;
- `flow` начинается с `xtls-rprx-vision`.

Порядок параметров в ссылке значения не имеет. Исходные ключи не декодируются,
не перекодируются и не изменяются.

Это фильтр по геометке исходной подписки. Он не может дать абсолютную гарантию
для ошибочно размеченного узла или конфигурации через CDN. После подключения
проверьте фактическую страну выходного IP на `https://ipinfo.io`.

## Важно

- Не помещайте личные или платные ключи в публичный репозиторий.
- Если исходник недоступен, в общем профиле осталось меньше пяти записей или в
  строгом профиле не осталось ни одной, workflow завершится с ошибкой и не
  затрёт последние рабочие файлы.
- GitHub Actions запускается по расписанию приблизительно: GitHub иногда
  задерживает запланированные задачи на несколько минут.
- GitHub может отключить расписание публичного репозитория после 60 дней без
  активности. В этом случае откройте вкладку Actions и снова включите workflow.
